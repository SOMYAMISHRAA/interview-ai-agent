# Interview AI Agent

An adaptive AI interviewer that conducts personalized technical interviews based on a candidate's learning journey through the ABTalks AI Cohort.

## Tech Stack

- FastAPI
- Next.js
- GPT-5.5
- FAISS
- Tailwind CSS

## Features

- Adaptive interview flow
- Curriculum-aware questioning
- Session memory
- Dynamic follow-up questions
- Structured interview feedback
